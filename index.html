Unity Browser Game

Card Duel

A solo C#/Unity strategy game combining a 6×6 exploration grid with turn-based card combat. ScriptableObject-based effects, validated card costs and targets, and turn-based status effects support the combat system. An in-game LLM enemy evaluates combat state, player move patterns, and component health to select attacks, with low-health and edge-case scenarios used to validate decisions. JSON saves preserve combat state and reward claims across reloads. Play the browser build on the dedicated game page, powered by Unity Play.

Course Seat Tracker & AI Assistant

CourseFlow

A responsive React/TypeScript PWA for searching Northeastern course seats using public Banner data. The free app supports local watchlists, seat thresholds, history, and alerts, with checks while the page is visible. No account is required. A 116 KB bilingual TF-IDF intent classifier, trained in Python and deployed in-browser, grounds replies in validated course queries without external LLM calls.

A separate Java/Spring Boot edition adds PostgreSQL-backed accounts, email-code login, session/CSRF protection, per-user watchlists, shared polling, and a transactional notification outbox with retries. JUnit, proxy, and Playwright tests cover isolation, retry handling, and unpublished terms, including 31 assistant checks and PostgreSQL integration in GitHub Actions.
