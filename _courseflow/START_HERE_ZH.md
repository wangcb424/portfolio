# 从这里开始：CourseFlow

打开 https://wangcb424.github.io/portfolio/courseflow/ 即可使用免费公开版。不需要安装 Java、Node、Docker，也不需要 GitHub、ChatGPT 或学校账号。

## 第一次使用

1. 选择学校开放查询的学期，输入课程代码，例如 `CS3100`，点击搜索。
2. 查看各 section 的 CRN、剩余席位、上课信息和最近查询时间。
3. 点击 Track，把想要的 section 加入当前浏览器的关注列表。
4. 在 My watchlist 设置提醒阈值、暂停或移除关注；页面保持打开且可见时会约每 5 分钟检查。
5. 在 Alerts 查看本机提醒，在 History 查看实际观察到的变化。
6. 换设备时先导出关注列表，再在另一设备导入。导入后会重新查询席位。

免费版不会在关闭网页、锁屏或浏览器暂停页面后持续监控。浏览器系统通知属于可选功能，受设备和权限限制；没有通知权限也可查询和关注。

关注和历史保存在自己的浏览器中。清除浏览器数据会删除它们；多人共用一个浏览器用户配置会共用本机列表。不会把一个访客的列表显示给另一个独立访客。

## 用中英文询问课程助手

点击 **AI assistant**，可以问“CS3100 还有空位吗？”“比较 CS3100 和 CS3520”或“我的关注里哪些有位？”。助手使用随网页加载的本地意图识别模型，实际余位来自课程接口；不用注册或填写 API key。它不是通用聊天大模型，也不会替你注册课程。详细说明见 [免费课程助手](docs/AI_ASSISTANT_ZH.md)。

## 手机与电脑

现代手机、平板和电脑浏览器都可以打开这个网址。支持时可以添加到主屏幕或安装 PWA，普通网页查询无需安装。已验证的具体浏览器环境见 [验证记录](docs/VERIFICATION.md)，并不声称已经在所有机型上测试。

学校接口出现故障时页面会显示错误或过期状态；请以学校注册系统为最终依据。本项目只查询和提醒，不会自动注册课程。

## 免费版和 Java 完整版

[免费版说明](docs/FREE_EDITION_ZH.md) 列出两者的功能差异。源码保留 Java / Spring Boot / PostgreSQL 的完整版本，供学习、面试演示或另行部署。在线免费版没有使用 Java 后台或数据库账号同步。

开发者运行完整 Java 演示：安装 JDK 17+ 和 Node 24 后，Windows 双击 `Build-Demo.cmd`，再运行 `Start-Demo.cmd`；macOS/Linux 使用 `sh scripts/build.sh`。构建后打开 `http://localhost:8080`。这是合成数据演示，验证码在页面显示，不会发送邮件。普通使用者无需这些步骤。

`PREVIEW.html` 是早期离线界面预览，数据全为模拟，不是当前在线查询入口。

## 可选快捷插件

`extension/` 是 Chrome/Edge 的开发者模式快捷入口，填入上方完整网站地址。在其他页面选中课程代码再打开插件，可以带着代码进入 CourseFlow。它尚未上架扩展商店；手机直接使用网页即可。
