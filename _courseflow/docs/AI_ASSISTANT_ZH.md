# 免费课程助手

打开 [CourseFlow](https://wangcb424.github.io/portfolio/courseflow/)，选择 **AI assistant** 即可使用。无需登录、API key、安装开发软件或下载大模型。

这是一个**本地机器学习意图分类器 + 课程查询工具 + 确定性回答**组成的轻量助手，不是 ChatGPT 类通用大语言模型。它把中英文问题分类，再通过已有公开查询接口获取课程数据。训练后的模型随网页一起加载，在浏览器 CPU 上运行，不需要 WebGPU。

## 可以问什么

- `CS3100 还有空位吗？`
- `Compare CS3100 and CS3520`
- `Spring 2027 的 CS3100 有哪些班？`
- `我的关注里哪些还有位？`
- `关闭网页后还会通知我吗？`
- `我的数据保存在哪里？`

输入完整课程代码，例如 CS3100；查询具体学期时同时写明年份和学期。没有指定学期时使用页面当前选择的学期，并在回答中说明。学校尚未开放的学期不会被替换成其他学期。

查询结果显示班级 CRN、查询时间和来源。比较仅根据公开席位和已有上课信息，不推断课程难度、教授评分、选课资格或未来空位。想关注某个班级时，需要亲自点击该班级的 Track 按钮；输入聊天文字不会自动注册课程、删除关注或修改阈值。

一次新查询最多比较两门课程；检查关注列表时，一次最多刷新三个“学期＋课程”组，其余会明确列为未检查。这样可以控制学校查询请求量，不把未检查的课程误报为已满。

## 免费和设备兼容

意图识别不调用付费模型 API，使用者和站主无需为每次对话支付推理费用；没有接入任何付费 AI 服务。网页和学校查询仍使用原有托管及查询接口，原有网络、限流和服务可用性限制继续适用。

无需下载数百 MB 的语言模型。现代手机和电脑浏览器都可以使用这个轻量实现，但不承诺所有旧设备或浏览器版本都兼容。课程查询需要联网；本地意图识别不等于离线可以获得实时余位。

## 数据与准确性

- 对话只在本次页面会话内保留，刷新会清除；不发送给外部语言模型服务。
- 为查询课程，程序只向现有接口发送学期和课程代码。
- 回答使用查询返回的数据与时间，不用模型生成席位数字。
- 查询失败、数据过期、只查到部分课程时，结果会明确标注限制。
- 系统只识别有限的课程相关意图；无法理解时会请你换一种说法，不会用自由生成的内容补全未知事实。
- 免费版仍然只在页面打开、可见且在线时进行定时监控。增加助手不会让关闭页面后的监控变成可用。

## 从代码理解每个部分

1. **聊天界面**：`frontend/src/Assistant.tsx` 收集问题、展示消息和已有课程卡片；`App.tsx` 把它接入导航和关注功能。
2. **意图分类**：`frontend/src/assistant/` 中的分类器把文字切成相邻 2–3 个字符的特征，计算 TF-IDF 权重，再比较它与各意图的中英文原型向量有多接近。这些向量由训练样本计算得到；模型约 116 KB，不是只把界面包装成聊天。
3. **参数校验与工具执行**：`engine.ts` 提取完整课程代码、核对可用学期、限制查询数量，再调用现有课程接口。
4. **回答构建**：只根据工具结果生成固定格式说明与课程卡片；低置信或不支持的问题走明确的兜底回复。
5. **模型复现**：`assistant-model/` 保存合成训练数据、独立评估数据和训练脚本；不使用用户聊天记录训练。
6. **测试**：`tests-assistant-unit/` 验证分类与查询逻辑，`tests-assistant/` 验证浏览器交互、手机布局和错误状态。

模型使用 198 条人工合成训练句。冻结模型后，一次独立的 56 条手工问题评估得到 50 条分类正确；其中支持范围内 39/42，域外拒识 11/14。这个小样本结果不是实际用户准确率，也不是整个助手的正确率。分类会出错，因此仍有课程代码、学期、只读操作和数据来源校验；不能把分类分数当成可靠概率。详细复现方法和误分类样例保留在 `assistant-model/`。

## 简历如何准确描述

可以描述为：开发中英文课程助手，使用浏览器本地意图分类模型、经过校验的课程查询工具和基于来源的回答，并通过自动化测试覆盖未公布学期、接口失败和设备布局。

不要写成已部署 GPT、训练了通用 LLM，或拥有无限准确的课程推荐能力。Java / Spring Boot / PostgreSQL 完整版仍保留在同一项目中；公开助手运行在免费网页端。
